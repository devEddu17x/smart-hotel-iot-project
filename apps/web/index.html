Smart Hotel IoT — AWS Services

  • AWS SAM / CloudFormation: Infrastructure as Code (Nested Stacks for dev, qa, prod)
  • AWS IoT Core: MQTT over TLS (ESP32 / Raspberry Pi), Device Shadow, IoT Rules, MQTT over WSS
  • Amazon Cognito: User Pool, Identity Pool, and PreTokenGeneration Lambda trigger
  • Amazon API Gateway (HTTP API v2) & AWS Lambda: REST commands, camera URLs, and user/RFID CRUD
  • Amazon DynamoDB: Users, RFID cards, and building event history
  • Amazon Kinesis Video Streams: Live HLS video streaming from Raspberry Pi Zero
  • Amazon S3 & CloudFront (OAC): ESP32-CAM snapshots and Web SPA hosting
